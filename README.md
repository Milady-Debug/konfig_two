# depviz — этап 1. Минимальный прототип с конфигурацией

CLI-приложение, настраиваемое конфигурационным файлом формата CSV
(строки вида `ключ,значение`).

Настраиваемые параметры:

| Ключ           | Назначение                                                   |
|----------------|--------------------------------------------------------------|
| `package_name` | Имя анализируемого пакета                                    |
| `repository`   | URL репозитория или путь к файлу тестового репозитория       |
| `test_mode`    | Режим работы с тестовым репозиторием (`true` / `false`)      |

При запуске все параметры выводятся в формате ключ-значение.

## Структура репозитория

```
src/depviz.py        — исходный код приложения
tests/test_depviz.py — тесты (unittest)
config.csv           — пример конфигурации
run.bat, run.sh      — скрипты запуска
```

## Запуск

```bash
run.bat                                # Windows
./run.sh                               # Linux/macOS
python src/depviz.py --config config.csv   # напрямую
```

## Тесты

```bash
python -m unittest discover tests
```

## Обработка ошибок

Реализована для всех параметров:

- конфигурационный файл не найден / не читается / не CSV в UTF-8;
- строка не в формате `ключ,значение` (не 2 колонки), пустой ключ,
  повторяющийся ключ;
- неизвестные или отсутствующие обязательные параметры;
- пустые `package_name` и `repository`;
- `test_mode`, отличный от `true`/`false`;
- в тестовом режиме — несуществующий файл тестового репозитория;
- в обычном режиме — `repository`, не являющийся http(s) URL.

При любой ошибке приложение выводит сообщение в stderr и завершается
с кодом 1.
