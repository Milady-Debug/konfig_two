# depviz — визуализация графа зависимостей (вариант №13)

CLI-инструмент на Python 3 (только стандартная библиотека) для анализа
зависимостей Maven-пакетов. Готовые менеджеры пакетов и сторонние
библиотеки для получения зависимостей не используются: pom.xml
загружается по HTTP через `urllib` и разбирается вручную через
`xml.etree.ElementTree`.

Ветка `main` содержит итоговую версию проекта (этапы 1–3). Разработка
по этапам сохранена в ветках `stage-1`, `stage-2`, `stage-3`; каждая
следующая ветка основана на предыдущей.

## Структура репозитория

```
src/depviz.py        — исходный код приложения
tests/test_depviz.py — тесты (unittest, стандартная библиотека)
config.csv           — конфигурация для реального Maven-репозитория
config_test.csv      — конфигурация для тестового репозитория
cfg_cycle.csv, cfg_multi.csv, cfg_missing.csv — конфиги демо-случаев
test_repo*.txt       — файлы тестовых репозиториев
run.bat, run.sh      — скрипты запуска
```

## Запуск

```bash
run.bat                                       # Windows
./run.sh                                      # Linux/macOS
python src/depviz.py --config config_test.csv # напрямую
```

## Тесты

```bash
python -m unittest discover tests
```

## Конфигурация (CSV, `ключ,значение`)

| Ключ           | Назначение                                                   |
|----------------|--------------------------------------------------------------|
| `package_name` | Пакет: `groupId:artifactId:version` (Maven) или имя из больших латинских букв (тестовый режим) |
| `repository`   | URL Maven-репозитория или путь к файлу тестового репозитория |
| `test_mode`    | Режим тестового репозитория (`true` / `false`)               |

## Возможности по этапам

- **Этап 1** — настройка через CSV-конфигурацию, вывод параметров в
  формате ключ-значение, обработка ошибок всех параметров.
- **Этап 2** — получение прямых зависимостей пакета из Maven-репозитория
  по URL: ручное построение адреса pom.xml, HTTP-загрузка, разбор XML
  (подстановка `${...}`, наследование от `<parent>`).
- **Этап 3** — построение графа зависимостей с учётом транзитивности
  алгоритмом DFS с рекурсией, обнаружение циклических зависимостей,
  режим тестового репозитория (пакеты — большие латинские буквы).
