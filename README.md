# depviz — визуализация графа зависимостей (вариант №13)

Инструмент визуализации графа зависимостей для менеджера пакетов.
Готовые средства (менеджеры пакетов, сторонние библиотеки) для получения
зависимостей не используются — pom.xml загружается по HTTP и разбирается
вручную средствами стандартной библиотеки Python.

## Ветки

Основная ветка `main` код этапов не содержит. Каждый этап находится в своей
ветке:

| Ветка    | Содержимое                                                        |
|----------|-------------------------------------------------------------------|
| `stage-1` | Этап 1. Минимальный прототип с конфигурацией (CSV)                |
| `stage-2` | Этап 2. Сбор данных о прямых зависимостях (формат Maven)          |
| `stage-3` | Этап 3. Граф зависимостей: DFS с рекурсией, циклы, тестовый режим |

Каждая следующая ветка основана на предыдущей, поэтому `stage-3` содержит
полную функциональность этапов 1–3.

## Запуск

Требуется только Python 3.8+, сторонние пакеты не нужны.

```bash
git checkout stage-3        # выбрать нужный этап
python depviz.py --config config_test.csv   # тестовый репозиторий
python depviz.py --config config_maven.csv  # реальный Maven-репозиторий
```
